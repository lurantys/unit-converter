Unit
Converter

Temperature, length and weight, converted by a small Python program, tested with pytest and built by three students on GitHub.

What it converts and who built it

Temperature

Celsius, Fahrenheit, Kelvin. Refuses anything below absolute zero.

Aymen Nhaila @lurantys

Length

Meters, kilometers, centimeters, miles. Refuses negative lengths. Also built this page.

Douaa Moutawakkil @douaamoutawakkildd-svg

Weight

Kilograms, grams, pounds. Also set up GitHub Actions to run the tests on every push.

Malak Baddi @m4lak-b

Run it yourself

You need Python 3 and Git. These commands download the project and run every test.

git clone https://github.com/lurantys/unit-converter.git
cd unit-converter
pip install -r requirements.txt
python -m pytest
